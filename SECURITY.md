# Security Policy

Totipo is security-sensitive software. Published Java libraries are available;
the API and storage SPI remain experimental, with no source/binary stability
promise. See the [README](README.md) for the current release and qualification
limits. Publication does not establish a security audit.

Please do not report suspected vulnerabilities in a public issue. Use GitHub's
private vulnerability-reporting mechanism when it is enabled for this
repository; otherwise contact the repository maintainers privately.

Protocol/specification issues should be reported against the specification
repository when they are not specific to this Java implementation.
